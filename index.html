碰一下就打開

把這個網址寫進 NFC 貼紙，貼在手機殼上。對方的手機靠過來，就會打開這張名片。

eight826.github.io/will.lu.08.github.io

怎麼寫入與貼上
  1. 1用 Android 的 Chrome 打開這頁，按「寫入 NFC 貼紙」，再把空白貼紙靠在手機背面。
  2. 2寫好後貼在手機殼上。之後把你的手機靠向對方的手機，對方就會看到這張名片。
  3. 3沒有貼紙時，請對方掃 QR，或按「靠近分享」。Android 用 Quick Share，iPhone 用 AirDrop。

手機上的網頁沒辦法模擬 NFC 標籤，所以兩支手機不能靠網頁直接互傳。iPhone 可以讀貼紙；若要寫入，請用 Android Chrome，或用 NFC Tools 寫進 NTAG213／215 貼紙。寫入的內容只有這個公開網址。
