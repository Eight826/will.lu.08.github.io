    請把你的手機碰一下我的手機。碰到之後，聯絡方式才會出現。

    只知道這個網站、或是別人轉傳公開網址，都打不開。

      寫進我的手機

      這組按鈕只在你自己的開啟連結裡出現。寫入貼紙時會一併寫入鑰匙，對方碰一下才進得來。

      怎麼寫入與貼上
      1. 1用 Android 的 Chrome 打開你自己的開啟連結，按「寫入 NFC 貼紙」，再把空白貼紙靠在手機背面。
      2. 2貼在手機殼上。之後對方的手機碰一下，才會看到聯絡方式。
      3. 3不要把打開後的網址轉傳出去。QR 和 AirDrop 也等於把鑰匙交出去，所以這頁沒有提供。

      網頁沒辦法證明「這一碰來自某一支特定的手機」。貼紙裡的網址就是鑰匙，別人若用 NFC 讀取那張貼紙，也可以複製。這把鎖擋得住只有公開網址的人。iPhone 可以讀貼紙；寫入請用 Android Chrome，或用 NFC Tools 寫入同一個開啟連結。NTAG213 或 NTAG215 都可以。
